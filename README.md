## 📋 Project Overview
This project is one of my first complete networking labs built in **Cisco Packet Tracer** while studying networking fundamentals alongside Cyber Security.

The goal was to design and deploy a small enterprise-style network connecting multiple locations through a simulated ISP infrastructure while implementing core networking services and security-focused segmentation.

## Features

* **VLANs:** Network segmentation for traffic isolation.
* **Routing:** Inter-VLAN communication and multi-site connectivity through routed WAN links (Static and Dynamic Routing).
* **Core Services:** Dynamic IP address allocation (DHCP) and DNS server configuration for name resolution.
* **Telephony:** VoIP deployment with functional IP phone communication.
* **Validation & Troubleshooting:** End-to-end connectivity checks using Ping, Traceroute, and routing verification.

## Technologies Used

* Cisco Packet Tracer
* Cisco Routers & Switches
* VLANs, DHCP, DNS, VoIP
* Static & Dynamic Routing

## Learning Objectives

This project helped me gain practical experience with:

* Network design, segmentation, and packet forwarding concepts.
* Enterprise network services deployment and basic VoIP implementation.
* Troubleshooting network communication issues.
* Understanding how data travels across interconnected networks (CCNA & Cyber Security learning paths).

## Project Outcome

Successfully built and tested a fully functional multi-site network where devices could communicate across locations, resolve domain names, receive IP addresses automatically, and perform voice communication through IP phones.
