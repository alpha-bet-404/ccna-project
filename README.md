# Multi-Site Enterprise Network Simulation (Cisco Packet Tracer)

This project is one of my first complete networking labs built in Cisco Packet Tracer while studying networking fundamentals alongside Cyber Security.

The goal was to design and deploy a small enterprise-style network connecting multiple locations through a simulated ISP infrastructure while implementing core networking services and security-focused segmentation.

## Features

* VLAN-based network segmentation for traffic isolation
* Inter-VLAN communication and routing configuration
* Multi-site connectivity through routed WAN links
* Dynamic IP address allocation using DHCP
* DNS server configuration and name resolution
* VoIP deployment with IP phone communication
* End-to-end connectivity validation using Ping and Traceroute
* Network troubleshooting and routing verification

## Technologies Used

* Cisco Packet Tracer
* Cisco Routers
* Cisco Switches
* VLANs
* DHCP
* DNS
* VoIP
* Static and Dynamic Routing
* Network Troubleshooting Tools

## Learning Objectives

This project helped me gain practical experience with:

* Network design and segmentation
* Routing and packet forwarding concepts
* Enterprise network services deployment
* Basic VoIP implementation
* Troubleshooting network communication issues
* Understanding how data travels across interconnected networks

## Project Outcome

Successfully built and tested a fully functional multi-site network where devices could communicate across locations, resolve domain names, receive IP addresses automatically, and perform voice communication through IP phones.

This project significantly improved my understanding of networking fundamentals and provided hands-on experience with concepts commonly covered in CCNA and Cyber Security learning paths.
